# Data Sources and Governance

## Intended Data Sources
- Official Vietnamese legal databases and government portals
- Internal legal document archives and verified notes
- Structured tax guidance and reference updates

## Governance Rules
- Use only authoritative and verifiable sources
- Maintain citation mapping between AI answers and source records
- Label demo content as sample-only
- Require source verification before publication or summarization

## Current Prototype Status
The current app intentionally renders an empty state until a verified legal source and backend data access layer are configured.
